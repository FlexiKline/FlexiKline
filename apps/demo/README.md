# FlexiKline Demo

[FlexiKline](../packages/flexi_kline/) 的示例应用，用于演示蜡烛图（K 线）绘制与交互的各类用法。

## 运行

```bash
flutter run
```

支持 Android、iOS、macOS、Linux、Windows、Web 多端运行。

## 目录结构

```
apps/demo/
├── lib/       # 示例页面（后续逐步补充）与入口
├── test/      # Widget 测试
└── android/ ios/ macos/ linux/ windows/ web/   # 各平台工程
```
