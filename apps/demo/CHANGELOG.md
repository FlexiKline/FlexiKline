## 1.0.0+1
* First tagged release of the demo app, built against `flexi_kline` 2.8.0 and `flexi_painting` 0.1.0.
* The demo has its own version, independent of `flexi_kline`, because it also uses `flexi_painting` and other packages. Bump major.minor.patch when the demo changes. The `+N` build number is the Android `versionCode`; increase it with every distributed build.
